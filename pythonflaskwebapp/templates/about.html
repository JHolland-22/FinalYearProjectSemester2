How to use this

Start up both virtual machines using the start button, when finished with virtual machine press the stop button.

How to ssh into virtual machine (s)

Kali Linux machine -> ssh -i key-given.pem kali@public-ip-address

Windows XP machine -> ssh -i key-given.pem ubuntu@public-ip-address

How to test that it is working

Ping Kali Linux public ip in Windows virtual machine and visa versa
